# RoundBell — бізнес-ідея

> Таймер раундів для боксу, кікбоксингу та інтервальних тренувань. PWA на GitHub Pages.

**Статус:** готово до старту розробки · 16.11.2026

## Ухвалені рішення

- **Назва:** RoundBell
- **Стек:** React + Vite
- **Інтерфейс:** англійською
- **Репозиторій:** публічний (open source)
- **Хостинг:** GitHub Pages

## Проблема

Нормальний таймер раундів для самостійних тренувань або з рекламою, або за підписку.

- Безкоштовні застосунки перебивають тренування рекламою або ховають потрібне за платною версією.
- У більшості всі раунди однакові: не можна змінити довжину одного конкретного раунду чи паузи.
- Екран телефону гасне посеред раунду, а в рукавичках його не розблокуєш.

## Для кого

Перший користувач — автор (dogfooding), далі люди, які тренуються раундами без тренера з дзвінком.

- **Аматори боксу й кікбоксингу**: груша, shadow, лапи самостійно в залі чи вдома.
- **Інтервальні тренування**: скакалка, HIIT, функціоналка з роботою та паузами.
- **Сценарій**: телефон лежить поруч або в кишені, звук іде в навушники, руки зайняті рукавичками.

## Рішення й цінність

Безкоштовний веб-таймер без реклами: задаєш раунди, отримуєш список слотів, правиш будь-який і тренуєшся.

1. Вказуєш кількість раундів, їхню тривалість і тривалість пауз.
2. Застосунок генерує список слотів: раунд, пауза, раунд…
3. Тицяєш на конкретний слот і міняєш його довжину.
4. Start — екран не гасне, сигнали йдуть у навушники, у будь-який момент пауза або стоп.

**Чим кращий за аналоги:** без реклами й підписок, без встановлення з магазину, окремі слоти можна редагувати.

## MVP

Перша версія — це один екран налаштувань і один екран таймера, без акаунтів і бекенду.

**У скоупі:**

- [ ] Форма: кількість раундів, тривалість раунду, тривалість паузи
- [ ] Генерація списку слотів і редагування довжини окремого слота
- [ ] Start / Pause / Stop
- [ ] Звуки: старт раунду, попередження за 10 с, кінець раунду
- [ ] Екран не гасне під час таймера
- [ ] Великі цифри й колір фону за станом: раунд / пауза
- [ ] Збереження останнього конфігу
- [ ] Встановлення на головний екран і робота офлайн (PWA)

**Поза скоупом MVP:** акаунти та синхронізація, історія тренувань, готові програми, робота при заблокованому екрані, інтеграція з Garmin.

## Технічний підхід

Статична PWA на React + Vite, деплой на GitHub Pages: без бекенду, HTTPS даром, деплой через push.

| Частина | Рішення |
| --- | --- |
| Стек | React + Vite, `vite-plugin-pwa` для manifest і service worker |
| Модель даних | Список слотів `{ type: 'work' \| 'rest', duration }`; стани `idle → running ⇄ paused → done` |
| Точність часу | Зберігати `endTime` і показувати `endTime - performance.now()`, не декрементувати секунди |
| Екран не гасне | Screen Wake Lock API, повторний запит на `visibilitychange` |
| Звук | Web Audio API, біпи через `OscillatorNode`; `AudioContext` розблоковувати на натисканні Start |
| Збереження | `localStorage` для останнього конфігу |
| Офлайн | Web App Manifest + service worker |
| Вібрація | `navigator.vibrate()` — лише Android, на iOS цього API немає |
| Деплой | GitHub Actions → GitHub Pages; у `vite.config` виставити `base: '/round_bell/'` |

**Ризики:**

- При заблокованому екрані браузер, особливо на iOS, зупиняє JS, і сигнали не звучать. Тому wake lock — обов'язкова частина MVP.
- Wake Lock у standalone-PWA на iPhone довго мав баг; перевірити на своєму телефоні в браузері та на головному екрані.

## Модель

Безкоштовний open-source проєкт без монетизації: його цінність — власний інструмент, портфоліо та контент для IT Friday.

- **Витрати:** нуль, хостинг на GitHub Pages.
- **Можливо пізніше:** кнопка донату, якщо з'явиться аудиторія.
- **Метрика успіху MVP:** сам користуєшся ним на кожному самостійному тренуванні замість інших застосунків.

## Роадмап

Спершу таймер для себе, потім програми й інтеграції. Дати етапів ще не визначені.

| Етап | Що входить |
| --- | --- |
| 1 · MVP | Слоти, пауза, стоп · звуки в навушники · wake lock і PWA |
| 2 · Програми | Готові програми · історія тренувань · збережені пресети |
| 3 · Інтеграції | Інтеграція з Garmin · Bluetooth-кнопки реакції · модуль для scrum poker |

До етапу 2 переходимо, коли MVP стабільно працює на власних тренуваннях.
